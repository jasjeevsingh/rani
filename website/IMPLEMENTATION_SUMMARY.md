## 🐛 Common Issues & Solutions

**Q: Website doesn't show up on GitHub Pages**
- Wait 5 minutes after enabling
- Check Settings → Pages for errors
- Verify branch and folder correct

**Q: Images don't load**
- Check file paths (case-sensitive!)
- Ensure images committed to Git
- Use relative paths: `assets/image.png`

**Q: Mobile menu not working**
- Clear browser cache
- Check JavaScript console
- Test on real device

**Q: GitHub stars not loading**
- Check API rate limit (60/hour)
- Verify repo name in script.js
- Check browser console
